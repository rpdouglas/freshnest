# 📜 Changelog

## [v0.4.0] - 2026-01-15
### Added
* **The Field Companion:** A dedicated "Work Mode" UI for active jobs.
* **Icon Checklists:** Visual task management designed for ESL workers.
* **Evidence Locker:** Integrated photo uploading (Before/After) with timestamps.
* **Smart UI:** Cards automatically offer "Continue Job" when work is in progress.
* **Admin Visibility:** Jobs table now shows real-time task completion % and evidence counts.

## [v0.3.0] - 2026-01-15
* **Conflict Engine:** Hard blocks for Recovery meetings and Soft blocks for Transit buffers.

## [v0.2.0] - 2026-01-15
* **Financial Guardrails:** ODSP Earning Cap enforcement.
